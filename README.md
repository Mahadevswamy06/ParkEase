## 🚀 Overview

**ParkEase** is a world-class, cyberpunk-inspired Smart Parking SaaS application designed for modern Indian cities. Built with React 19, Vite, and Framer Motion, it delivers a high-end luxury dark-mode aesthetic with glassmorphism (`backdrop-filter`), ANPR optical license plate barrier telemetry, real-time slot reservation, and INR (₹) localization.

---

## ✨ Key Features

- **🌐 Live Production Deployment**: Deployed on Vercel with single-page SPA routing support (`vercel.json`).
- **🎨 Luxury Dark Glassmorphism UI**: Inspired by Stripe, Linear, Tesla, and Framer. Features radial ambient mesh glowing background lighting and custom typography.
- **⚡ ANPR Barrier Pass Integration**: Scans vehicle license plates (`DL-01-AB-1234`) for automated barrier gate entry.
- **📍 Multi-City Indian Parking**: Search and reserve spots across top Indian metros (New Delhi, Mumbai, Bengaluru, Hyderabad, Kolkata, Chennai).
- **🔑 Role-Based Access Control (RBAC)**: Dedicated Driver Portal and Admin Management Panel.
- **📸 Interactive Profile & Avatar Uploader**: Customizable user driver profiles with preset avatar selections and local custom photo file uploads.
- **📱 Fully Responsive**: Flawlessly adapts across mobile phones, tablets, and desktop workstations.

---

## 🛠️ Technology Stack

- **Frontend Core**: React 19, React Router v7, JavaScript (ES6+).
- **Build Tool**: Vite 6.0.
- **Styling**: Vanilla CSS3 with global CSS Custom Properties (Tokens), Glassmorphism, and Cyberpunk radial gradients.
- **Animations**: Framer Motion.
- **Icons**: Lucide React.
- **Charts & Data**: Recharts.
- **Deployment**: Vercel.

## 💻 Local Setup & Development

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Mahadevswamy06/ParkEase.git
   cd ParkEase
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the local development server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173` in your browser.

4. **Build for Production**:
   ```bash
   npm run build
   ```
